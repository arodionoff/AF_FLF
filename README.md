# Anti-Fraud "Fund-Loading" Firms

## Антифрод выдач физическим лицам на доходах от "Заливных" компаний

### Назначение модели

Данная модель нацелена на снижение рисков при выдаче займов субъектам на **основе фиктивного или искусственно созданного дохода**.
Под **«заливными компаниями»** обычно неформально понимают организации, через которые на счета физических лиц кратковременно переводят деньги, создавая видимость регулярной зарплаты или выручки, чтобы повысить шансы на кредит.

Что пытаются предотвратить

Схема обычно выглядит так:

Заёмщик или посредник создаёт/использует компанию с небольшим реальным оборотом либо без реальной хозяйственной деятельности.

На пенсионный счёт физлица начинают поступать переводы с назначением "Обязательные Пенсионные Отчисления" (**КНП "010"**), похожим на отчисления на настоящую зарплату, а также возможно социальные отчисления (**КНП "012"**).

Эти поступления используются кредитными учреждениями как «подтверждённый доход» в заявке на заём.

После получения займа деньги могут перестать поступать, а способность обслуживать долг оказывается существенно ниже заявленной.

Для кредитора это одновременно:

- риск невозврата;

- риск мошенничества с кредитом;

- риск выдачи по подложным/недостоверным сведениям;

- риск выдачи кредита лицу с чрезмерной долговой нагрузкой.

Антифрод‑проверка анализирует достоверность данных заявки, а также признаки аномальной активности, компрометации персональных данных и повторяющихся схем. Например, решения кредитных бюро сопоставляют сведения по правилам, скоринговым моделям и внешним источникам, после чего кредитное учреждение учитывает результат при принятии решения.
